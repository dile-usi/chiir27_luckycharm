# chiir27_luckycharm
## Supplementary Material

Supplementary material for the paper "The First One is a Lucky Charm": Children's Reasoning Behind Online Search Actions in the Classroom (submitted to CHIIR 2027, under double-anonymous review).

The material supports the qualitative analysis of primary-school children's reasoning while carrying out search tasks with a simulated search engine in the classroom. All data were coded inductively in ATLAS.ti. No transcripts or participant identifiers are included.


File Description
`codebook.xlsx`: Codebook of the reasoning codes and the frequency tables derived from the coding (four sheets, described below).

1. Reasoning codebook
One row per reasoning group and per code, with its definition, the number of coded quotations (n), the number of groups of children in which it occurs (out of 18), and example quotations from the India topic (grade 3) and the Space topic (grade 4). Quotes were translated from Italian by the authors, but originals can be found in the file.

2. Frequency per ID
Groups of children (ID01–ID18, with grade) in rows; reasoning codes, organised by reasoning group, in columns. Each group block ends with a Group total: the number of distinct quotations coded with at least one code of the group. A quotation can carry several codes, so a group total can be lower than the sum of its codes.

3. Reasoning per task type
Frequency of each reasoning code and group by task type (fact-finding, multi-step, open-ended). Values are normalized in ATLAS.ti to account for the different number of coded quotations per task type (N = 271, 387 and 461), so that columns are directly comparable; values are therefore non-integer. Percentages show the share of each reasoning across task types.

4. Reasoning per ISP stages
Code co-occurrence between reasoning codes and the six stages of the information-seeking process (problem definition, query formulation, results examination, information extraction, answer construction, answer submission), as absolute counts. `Gr` (groundedness) is the number of quotations coded with a code.

Notation

- ID01–ID18: groups of children (17 pairs, 1 group of three). Grade 3: ID01–ID08, ID17, ID18; grade 4: ID09–ID16.
- K1, K2, K3: children within the same group.
